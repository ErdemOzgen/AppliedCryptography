# Applied Cryptography

This repository contains a basic course-content layout for the Applied Cryptography syllabus.

## Structure

- `syllabus/part-1-provable-security/`: Theoretical foundations, proofs, and core primitives.
- `syllabus/part-2-practical-applications/`: Real-world systems, protocols, and advanced applications.

Each topic file includes:

- Topic overview placeholder
- Required readings
- Optional readings placeholder
- Materials checklist (`Slides`, `Quiz`)

## Quick Start

1. Open the topic file you want to prepare.
2. Add links to slide decks and quiz resources.
3. Expand notes and references for each session.
